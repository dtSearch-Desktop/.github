# dtSearch Desktop — full-text index of a local corpus you own

dtSearch Desktop keeps one named board on the desk: the live index, the filter in front of you, and a short note the next researcher can read. Extra hunts wait for their own title.

## Session Card

| Slice | What you do in dtSearch Desktop | What remains |
|-------|------------------------|--------------|
| Arrival | Open dtSearch Desktop and name today's research desk | A titled local corpus |
| Focus | Keep only live filters on the dtSearch Desktop board | A short index list |
| Check | Read dtSearch Desktop search filters before a large index change | A confirmed research desk |
| Handoff | Mark finished hunts inside dtSearch Desktop | A note for the next researcher |

## How dtSearch Desktop Sits

dtSearch Desktop does not replace a one-off hunt, the unlabeled filter dump, or an index of a corpus you do not own. It sits beside them as a named research desk for one job: which full-text index is live, which search filters still match the local corpus you own, and what the next researcher should read.

A first visit should be one short full-text pass on documents you own, then the same dtSearch Desktop research desk the next day. That is enough to see if the named search filters hold.

## Traffic Light

| Signal | On the dtSearch Desktop board | What you do |
|--------|----------------------|-------------|
| Green | Named local corpus, short live filter list | Continue the same full-text index |
| Amber | Two hunts mixed on one filter set | Split the corpus before a large change |
| Red | No title, no note, a one-off hunt | Stop and name the research desk first |
| Clear | Handoff written, live filters few | Close dtSearch Desktop and leave the research desk |

## Open Order

1. Open the last dtSearch Desktop research desk, not a new empty local corpus.
2. Read the search filters and the last handoff.
3. Finish one visible full-text pass inside dtSearch Desktop on documents you own.
4. Write what changed, then close with fewer one-off hunts than you found.
5. If the index feels crowded, drop anything that belongs to a different dtSearch Desktop hunt.

## After a Week

A week in dtSearch Desktop is not a larger one-off hunt. It is the same title, a shorter live filter list, and a note that still makes sense before the next full-text pass. Take finished hunts off the live set so the next visit starts on the research desk that is still open.

## Sign-off

- [ ] The dtSearch Desktop workspace name is short enough to scan
- [ ] Only a local corpus you own sits on the full-text index
- [ ] A second researcher can read the filter handoff
- [ ] The last dtSearch Desktop local corpus still opens after a restart
- [ ] Finished hunts are off the live dtSearch Desktop set
- [ ] The dtSearch Desktop summary still matches the search filters on the board

## Field Note

dtSearch Desktop is easier to trust when the research desk stays smaller than the one-off hunt it came from. Name the local corpus, keep the live filters, finish one visible full-text pass, and write what changed.
